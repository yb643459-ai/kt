# קול תורה — לוח שמחות

אתר סטטי (Cloudflare Pages) + Backend על Google Apps Script + Google Sheets.
שני לוחות: **מאורסים** ו**חתונות**, עם טופס הוספה שעובר אישור מנהל, ואפשרות דיווח.

## מבנה הקבצים
```
index.html          דף הבית - בחירת לוח
engaged.html         לוח המאורסים
weddings.html         לוח החתונות (טבלה + לוח שנה עברי)
admin.html            פאנל ניהול (סיסמה)
css/style.css         עיצוב
js/config.js          כתובת ה-Backend (לערוך!)
js/api.js              תקשורת עם ה-Backend
js/hebrew-calendar.js  המרת תאריכים לעברי (מבוסס Intl של הדפדפן)
apps-script/Code.gs    קוד ה-Backend להדבקה ב-Google Apps Script
```

## שלב 1: הקמת Google Sheet + Apps Script

1. צרו Google Sheet חדש (sheets.new). שימו לב לכתובת שלו:
   `https://docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit` — העתיקו את `SHEET_ID_HERE`.
2. היכנסו ל-[script.google.com](https://script.google.com) → **פרויקט חדש**.
3. מחקו את הקוד הקיים בקובץ `Code.gs`, והדביקו את כל התוכן מהקובץ `apps-script/Code.gs` שבתיקייה הזו.
4. בראש הקובץ ערכו את ההגדרות:
   ```js
   const SHEET_ID = 'הדביקו כאן את ה-ID של הגיליון';
   const ADMIN_PASSWORD = 'בחרו סיסמה חזקה למנהל';
   const NOTIFY_EMAIL = 'המייל שלכם, לקבלת התראות';
   ```
5. **(מומלץ, לצורך כיווניות RTL בגיליונות)**: בתפריט למעלה → **שירותים (Services)** → **+** → הוסיפו את **Google Sheets API**.
6. למעלה, בתפריט הפונקציות, בחרו `setup` ולחצו **הפעלה (▶)**. בפעם הראשונה תתבקשו לאשר הרשאות (Google Sheets + Drive + Gmail) — אשרו.
   פעולה זו יוצרת אוטומטית את כל הגיליונות הדרושים (מאורסים, מאורסים_ממתין, חתונות, חתונות_ממתין, דיווחים), תיקיית Drive לתמונות, מגדירה את הגיליונות מימין-לשמאל, ומתקינה את הטריגר לאישור/דחייה ישירות מהגיליון (ראו למטה).
   אם דילגתם על שלב 5, ה-RTL לא יוגדר אוטומטית — פשוט הריצו את `setup` שוב אחרי הוספת השירות, או הגדירו ידנית: לחיצה ימנית על לשונית כל גיליון → **מימין לשמאל**.
7. **פריסה** (Deploy) → **פריסה חדשה** → סוג: **אפליקציית אינטרנט (Web app)**.
   - להפעיל בתור: **עצמכם**
   - למי יש גישה: **כל אחד (Anyone)**
8. אשרו שוב הרשאות אם מתבקש, ותקבלו כתובת URL שמסתיימת ב-`/exec`. שמרו אותה.

> **חשוב:** בכל פעם שאתם משנים את הקוד ב-Apps Script, יש לבצע **פריסה חדשה** (או "ניהול פריסות" → עריכה) כדי שהשינויים ייכנסו לתוקף.

## שלב 2: חיבור האתר ל-Backend

פתחו את `js/config.js` ועדכנו:
```js
const CONFIG = {
  APPS_SCRIPT_URL: 'https://script.google.com/macros/s/.../exec', // הכתובת משלב 1.7
  ...
};
```

## שלב 3: פריסה ל-Cloudflare Pages

**אפשרות א' - דרך Git (מומלץ):**
1. העלו את כל תיקיית הפרויקט לריפו ב-GitHub.
2. ב-Cloudflare Dashboard → **Workers & Pages** → **צור** → **Pages** → **חבר ל-Git**.
3. בחרו את הריפו. אין צורך בפקודת build — זהו אתר סטטי טהור (השאירו את שדה ה-build ריק, ותיקיית הפלט `/`).
4. לחצו **שמור ופרוס**.

**אפשרות ב' - העלאה ישירה:**
1. Cloudflare Dashboard → **Workers & Pages** → **צור** → **Pages** → **העלה תיקייה**.
2. גררו את כל תוכן התיקייה (לא כ-zip, הקבצים עצמם) ולחצו **פרוס**.

לאחר הפריסה תקבלו כתובת כמו `kol-torah.pages.dev` — זה האתר החי.

## איך זה עובד

- **צפייה**: כל דפי הלוח שולפים ישירות מה-Google Sheet (טבלאות "מאורסים"/"חתונות") דרך קריאת `GET` ל-Apps Script.
- **הוספה**: טופס "הוספה" שולח את הפרטים לגיליון "ה_ממתין" המתאים, ושולח מייל התראה אוטומטי אליכם.
- **אישור מנהל**: נכנסים ל-`admin.html`, מזינים את הסיסמה, ורואים את כל הפריטים הממתינים עם כפתורי **עריכה** (לתיקון פרטים לפני אישור), **אישור** ו**דחייה**. אישור מעביר את השורה לגיליון המאושר; דחייה מוחקת אותה. בפאנל הניהול יש גם רשימת "פריטים מפורסמים" עם אפשרות מחיקה — להסרת פריט שכבר עלה ללוח החי.
- **אישור ישירות מגוגל שיטס**: בגיליונות "מאורסים_ממתין" ו"חתונות_ממתין" יש עמודת **אישור** ראשונה (A) עם רשימה נפתחת. בחירה ב-"אשר" מעבירה את השורה אוטומטית לגיליון המאושר; בחירה ב-"דחה" מוחקת אותה. פועל דרך טריגר שמותקן אוטומטית ע"י `setup()`.
- **דיווח**: כפתור "דיווח למנהל" בכל לוח שולח הודעה חופשית (למשל טעות בפרטים) שנשמרת בגיליון "דיווחים" ונשלחת גם במייל.
- **הסרה אוטומטית של חתונות**: לוח החתונות מסנן בצד הדפדפן — חתונה מוצגת עד וכולל יום האירוע, ונעלמת אוטומטית מהיום שאחריו.
- **ניהול נתונים נוח**: אפשר תמיד לפתוח את הגיליון של Google Sheets ולערוך/למחוק ידנית כל שורה — האתר תמיד קורא ישירות משם.

## התאמה אישית

- **שינוי הסיסמה / המייל**: ערכו ב-`Code.gs` ופרסו מחדש (Deploy → Manage deployments → Edit → New version).
- **צבעים/עיצוב**: כל המשתנים בראש `css/style.css` (`--ink`, `--parchment`, `--wine`, `--gold`, `--teal`).
- **שינוי שם הישיבה**: ב-`js/config.js` (`SITE_NAME`) ובכותרות ה-`<title>`/`<h1>` בכל דף.

## פתרון בעיות נפוצות

- **"שגיאה בטעינת נתונים" / CORS**: ודאו שהפריסה ב-Apps Script היא עם "למי יש גישה: כל אחד", ושהעתקתם את כתובת ה-`/exec` (לא `/dev`).
- **סיסמת מנהל לא מתקבלת**: ודאו שביצעתם פריסה חדשה (Deploy) אחרי כל שינוי בקוד — Apps Script לא מעדכן פריסה קיימת אוטומטית.
- **תמונות לא מוצגות**: תמונה שהועלתה נשמרת בתיקיית Drive שנוצרה אוטומטית (`קול תורה - תמונות שמחות`) עם שיתוף "כל מי שיש לו את הקישור" — לצפייה.
